# Paradise Nursery Shopping Application

A responsive plant-shopping application built with React, Redux Toolkit, React Redux, and Vite. Visitors can browse 18 unique houseplants across three categories, add plants to a cart, change quantities, remove items, and see updated totals.

## Open the included preview

Extract the download, then double-click **OPEN-PREVIEW.html**. This self-contained build includes the application, styling, and plant illustrations. It works without installing Node.js or connecting to the internet.

The preview is included in the project download and regenerated by `npm run build`. It is excluded from Git because the editable source is the submission deliverable.

## Run the editable project

Install Node.js 22.12 or newer; Node.js 24 is supported. Open a terminal in the folder containing `package.json` and run:

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite, normally `http://localhost:5173`.

## Features

- Landing page with the Paradise Nursery name, a greenhouse background image, company information, and a **Get Started** button.
- Three plant categories, each containing six unique plants: **Easy-care Classics**, **Statement Foliage**, and **Flowering Favorites**.
- Each product displays a local thumbnail, name, description, price, and **Add to Cart** button.
- Adding a plant updates Redux state and disables that plant's button until the plant is removed from the cart.
- Shared navigation includes **Home**, **Plants**, and **Cart**. The cart badge counts total units, including quantity changes.
- The cart displays thumbnails, plant names, unit prices, quantities, per-plant totals, and the total cost.
- Increase, decrease, delete, and **Continue Shopping** controls update the interface immediately.
- Decreasing a quantity from one to zero removes that plant.
- **Checkout** displays a **Coming Soon!** message.
- Empty-cart handling, keyboard focus styles, accessible control labels, and layouts for small and large screens.

## Required submission files

| Task | File | Implementation |
| --- | --- | --- |
| 1 | `README.md` | Project name and details |
| 2 | `src/AboutUs.jsx` | Company information |
| 3 | `src/App.css` | Landing-page background image and responsive styling |
| 4 | `src/App.jsx` | Paradise Nursery landing page and Get Started navigation |
| 5 | `src/CartSlice.jsx` | Redux add, remove, and quantity-update reducers; total selectors |

`src/NavBar.jsx` is the reusable navigation component used on the landing, product, and cart pages. `src/store.js` configures Redux, and `src/main.jsx` supplies the store through React Redux's Provider.

## Test and build

```sh
npm test
npm run build
npm run preview
```

The six automated tests cover the catalog, adding items, disabled buttons, dynamic counts and prices, quantity controls, deletion, empty-cart recovery, checkout, navigation, and invalid quantities. The test that adds all 18 plants expects a total of **$485.00**.

`npm run build` produces `dist/` for static hosting and regenerates `OPEN-PREVIEW.html` for direct offline viewing. `npm run preview` serves the production build locally.

## Scope and assets

This is a front-end course project. The cart remains available while navigating in the current page session and resets on a full reload. No payment, account creation, inventory service, or backend is required; checkout intentionally displays the assignment's Coming Soon message.

The 18 plant thumbnails and greenhouse background are original local SVG illustrations in `src/assets/`. They require no external image service, API key, attribution to a stock provider, or network connection.
